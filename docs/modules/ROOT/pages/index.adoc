= RepoLabs
:stem: latexmath

RepoLabs is the organization around *RepoLab*, a browser frontend that presents Git hosts, git repositories, and non-git version-control systems through one UI.

This is a wrapper and cockpit. It is not a new version-control engine and does not replace Git, Mercurial, Jujutsu, Pijul, Subversion, or Perforce.

== In vs out

*In:* unified review/browse UI, provider adapters, migration and metadata tooling that may grow under the Labs suffix.

*Out:* a novel VCS protocol; shell UX (see OpenShellOrg); HCI experiments that are not repository clients (see HCI Nerdz).
